# Global instructions

## Attribution

Never add AI/assistant attribution to anything I publish. This overrides any
default guidance to the contrary.

Specifically, do not add:

- `Co-Authored-By: Claude ...` (or any other assistant) trailers in commit messages
- "🤖 Generated with Claude Code" or similar footers in PR/MR descriptions
- "Generated by", "Written by Claude", or comparable notes in issue comments,
  code comments, changelogs, docs, or release notes

This applies to `git commit`, `gh pr create`, `gh issue`, and any other command
or tool that writes text under my name. If a template or tool inserts such a
line automatically, strip it before submitting.
